
# Python自动文件整理助手

## 一、项目介绍

这是一个使用 Python 编写的自动文件整理工具。

它可以扫描指定文件夹，自动识别文件类型，
创建对应的分类文件夹，并复制文件到指定位置。

## 二、项目功能

1. 自动扫描文件夹
2. 自动识别文件类型
3. 自动创建分类文件夹
4. 自动复制文件
5. 统计各类型文件数量
6. 自动生成整理报告

## 三、支持的文件类型

| 文件类型 | 扩展名 |
|---|---|
| 文本文件 | txt |
| 表格文件 | csv |
| PDF文件 | pdf |
| 图片文件 | jpg、png、gif |
| Word文件 | docx |
| Excel文件 | xlsx |
| 压缩文件 | zip |
| 视频文件 | mp4 |
| 代码文件 | py |

## 四、使用方法

1. 安装 Python 3
2. 将需要整理的文件放入 test_files
3. 在终端运行：

```bash
python file_organizer.py
```

4. 在 output 文件夹查看整理结果

## 五、使用技术

- Python
- pathlib
- os
- shutil
- 函数
- 异常处理
